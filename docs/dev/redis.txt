Integrating Pydantic v2 with RedisJSON inside your FastAPI application creates a powerful, type-safe pipeline. Pydantic handles the HTTP request validation and serialization, while Redis stores the data natively as a high-performance document [Query-relevant Context].
Here is a complete, production-ready asynchronous example demonstrating how to validate an incoming agent task request, save it directly as a structured JSON document, and read it back cleanly.
Step 1: Define the Pydantic Schema
Create a structured schema using Pydantic. We will include nested models to showcase how elegantly RedisJSON handles deep data structures.
python
from typing import List,  Optional
from pydantic import BaseModel, Field, EmailStr

# A nested schema for sub-documents
class TaskTarget(BaseModel):
    host_ip: str
    os_platform: str = Field(description="Target OS like windows, linux")

# The main schema for incoming data
class JobPayload(BaseModel):
    job_id: str
    command: str
    arguments: List[str] = Field(default_factory=list)
    timeout_seconds: int = Field(default=300, ge=10, le=3600)
    target: TaskTarget
    created_by: Optional[EmailStr] = None
Use code with caution.
Step 2: Integrated FastAPI Code
This implementation handles the payload validation, safely formats the data for Redis, and writes it directly to the engine with disk persistence active.
python
import json
import redis.asyncio as aioredis
from fastapi import FastAPI, HTTPException, status
from pydantic import BaseModel

app = FastAPI()

# Asynchronous connection pool targeting your Memurai/Redis server
redis_pool = aioredis.ConnectionPool(host='localhost', port=6379, decode_responses=True)
r = aioredis.Redis(connection_pool=redis_pool)

@app.post("/tasks", status_code=status.HTTP_201_CREATED)
async def create_task(payload: JobPayload):
    """
    FastAPI automatically validates the incoming request against the JobPayload schema.
    If it fails, a clean 422 Unprocessable Entity error is returned to the client.
    """
    db_key = f"task:{payload.job_id}"
    
    try:
        # Pydantic v2 uses model_dump() instead of the deprecated dict() method.
        # This converts our complex Python model cleanly into a native dictionary structure.
        native_dict = payload.model_dump()
        
        # Save straight to RedisJSON. 
        # '$' specifies the root path of the document.
        await r.json().set(db_key, "$", native_dict)
        
        return {
            "status": "stored", 
            "key": db_key, 
            "job_id": payload.job_id
        }
        
    except Exception as e:
        raise HTTPException(
            status_code=status.HTTP_500_INTERNAL_SERVER_ERROR, 
            detail=f"Database write failed: {str(e)}"
        )

@app.get("/tasks/{job_id}", response_model=JobPayload)
async def get_task_by_id(job_id: str):
    """
    Retrieves the raw JSON document from Redis and instantiates it 
    back into a validated Pydantic model before returning it.
    """
    db_key = f"task:{job_id}"
    
    # Fetch the document from the root path
    raw_doc = await r.json().get(db_key, "$")
    
    if not raw_doc:
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND, 
            detail="Requested job profile could not be found."
        )
        
    # RedisJSON returns root elements enclosed within a list structure: [ {...} ]
    actual_data = raw_doc[0]
    
    # Re-validate and structure the output using Pydantic's factory method
    return JobPayload.model_validate(actual_data)
Use code with caution.
Core Structural Advantages of This Model
Native Field Operations ($.field): Because the document is stored natively via RedisJSON rather than as a flat string blob, you can dynamically run calculations directly inside the cache engine. For instance, if an agent wants to extend a running task's window, your code can patch just that single parameter asynchronously:
python
await r.json().set(f"task:{job_id}", "$.timeout_seconds", 600)
Use code with caution.
Elimination of Extra Validation Code: FastAPI intercepts mismatched schema values immediately at the edge. If an agent tries to push a string into timeout_seconds or passes an invalid parameter structure, the application bypasses Redis entirely and short-circuits the pipeline safely.
No String Conversion Bottlenecks: When building database abstraction layers using older methods, you constantly have to parse and stringify objects using json.loads() or json.dumps(). The combination of modern Python async clients and Pydantic abstractions removes this layer of management entirely.

Шаг 2. Работа с JSON и схемами в Python
Для работы с JSON вам не нужны другие библиотеки — официальный асинхронный клиент redis.asyncio, который вы уже используете для FastAPI, полностью поддерживает JSON-команды.
Вот пример кода, который создает JSON-документ, обновляет его части и делает по ним выборку:
python
import asyncio
import redis.asyncio as aioredis

async def main():
    # Подключаемся к Redis
    r = await aioredis.from_url("redis://localhost:6379", decode_responses=True)

    # 1. Создаем JSON-документ (аналог строки в таблице или документа в MongoDB)
    user_profile = {
        "name": "Николай",
        "age": 45,
        "skills": ["Python", "Azure", "DevOps"],
        "is_active": True,
        "address": {
            "city": "Brisbane",
            "country": "Australia"
        }
    }

    # Сохраняем JSON под ключом 'user:101'
    # '$' означает корневой элемент JSON-документа
    await r.json().set("user:101", "$", user_profile)
    print("[✓] JSON документ успешно сохранен!")

    # 2. Атомарное обновление отдельного поля (без перезаписи всего документа!)
    # Изменим возраст и добавим новый навык в массив
    await r.json().set("user:101", "$.age", 46)
    await r.json().arrappend("user:101", "$.skills", "Terraform")

    # 3. Выборочное чтение по JSON-пути (JSONPath)
    # Запросим только имя и массив навыков
    result = await r.json().get("user:101", "$.name", "$.skills")
    print("[~] Данные из базы:", result)
    
    await r.close()

if __name__ == "__main__":
    asyncio.run(main())

Шаг 3. Индексация и поиск по JSON (RediSearch)
Если вы хотите делать сложные поисковые запросы (например, "найди всех пользователей из города Brisbane, у которых возраст > 40"), обычного json().get() будет мало. Вам нужно создать Индекс поверх ваших JSON-документов с помощью встроенного модуля RediSearch.
Вот как это делается:
python
from redis.commands.search.field import TextField, NumericField
from redis.commands.search.indexDefinition import IndexDefinition, IndexType

async def setup_search_index(r):
    # Описываем схему индекса: какие поля внутри JSON мы хотим индексировать
    schema = (
        TextField("$.name", as_name="name"),
        NumericField("$.age", as_name="age"),
        TextField("$.address.city", as_name="city")
    )
    
    try:
        # Создаем индекс для ключей, которые начинаются с 'user:'
        await r.ft("idx:users").create_index(
            fields=schema,
            definition=IndexDefinition(prefix=["user:"], index_type=IndexType.JSON)
        )
        print("[✓] Индекс для поиска по JSON успешно создан.")
    except Exception as e:
        print("[!] Индекс уже существует или произошла ошибка:", e)

# Пример поискового запроса в коде:
# result = await r.ft("idx:users").search("@city:Brisbane @age:[40 INF]")
Use code with caution.

Скорость: Вы получаете гибкость базы данных MongoDB (работа с вложенными JSON-схемами), но со скоростью работы в оперативной памяти Redis.
Атомарность: Вы можете изменять глубоко вложенные поля JSON (например, добавить элемент в массив внутри документа) одной быстрой командой, не гоняя весь большой JSON-объект по сети туда-обратно.

ЧАСТЬ 1. Асинхронный API (Python / FastAPI)
Этот код предоставляет два метода: один для длинного опроса (/get-task), а второй — для подтверждения успешного выполнения (/ack-task).
python
import redis.asyncio as aioredis  # Используем асинхронный клиент!
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

# Инициализируем пул подключений при старте
redis_pool = aioredis.ConnectionPool(host='localhost', port=6379, decode_responses=True)
r = aioredis.Redis(connection_pool=redis_pool)

STREAM_NAME = "tasks_stream"
GROUP_NAME = "agents_group"

@app.on_event("startup")
async def startup_event():
    # Создаем группу, если её нет
    try:
        await r.xgroup_create(STREAM_NAME, GROUP_NAME, id='0', mkstream=True)
    except aioredis.exceptions.ResponseError:
        pass  # Группа уже существует

class AckRequest(BaseModel):
    task_id: str

@app.get("/get-task")
async def get_task(agent_id: str):
    try:
        # block=20000 усыпляет этот конкретный запрос на 20 секунд внутри Redis,
        # но за счет await Uvicorn свободно обрабатывает другие запросы.
        response = await r.xreadgroup(
            groupname=GROUP_NAME,
            consumername=agent_id,
            streams={STREAM_NAME: '>'},
            count=1,
            block=20000
        )
        
        if not response:
            return {"status": "no_tasks"}
            
        # Формат ответа Redis Streams: [[stream_name, [[message_id, payload]]]]
        stream_name, messages = response[0]
        message_id, payload = messages[0]
        
        return {
            "status": "success",
            "task_id": message_id,
            "data": payload
        }
    except Exception as e:
        raise HTTPException(status_code=500, detail=str(e))

@app.post("/ack-task")
async def ack_task(body: AckRequest):
    # Агент сообщает, что задача успешно выполнена
    try:
        await r.xack(STREAM_NAME, GROUP_NAME, body.task_id)
        return {"status": "confirmed"}
    except Exception as e:
        raise HTTPException(status_code=500, detail=str(e))
Use code with caution.
ЧАСТЬ 2. Код агента на Go (Golang)
В Go для поддержки Long Polling важно настроить HTTP-клиент с увеличенным таймаутом (больше, чем block на сервере), чтобы сам клиент не обрывал соединение раньше времени.
go
package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"net/http"
	"time"
)

const (
	apiURL  = "http://localhost:8000"
	agentID = "go_agent_01"
)

type APIResponse struct {
	Status string                 `json:"status"`
	TaskID string                 `json:"task_id"`
	Data   map[string]interface{} `json:"data"`
}

func main() {
	// Таймаут клиента 30 сек (больше, чем 20 сек ожидания на FastAPI)
	client := &http.Client{Timeout: 30 * time.Second}

	fmt.Printf("[*] Агент %s запущен...\n", agentID)

	for {
		url := fmt.Sprintf("%s/get-task?agent_id=%s", apiURL, agentID)
		resp, err := client.Get(url)
		if err != nil {
			fmt.Println("[!] Ошибка сети, повтор через 5 сек:", err)
			time.Sleep(5 * time.Second)
			continue
		}

		var res APIResponse
		json.NewDecoder(resp.Body).Decode(&res)
		resp.Body.Close()

		if res.Status == "no_tasks" {
			// Длинный опрос завершился по таймауту, сразу идем на следующий круг
			continue
		}

		if res.Status == "success" {
			fmt.Printf("[~] Получена задача %s: %v\n", res.TaskID, res.Data)
			
			// --- Здесь логика выполнения задачи ---
			time.Sleep(1 * time.Second) 
			
			// Отправляем ACK (подтверждение)
			ackBody, _ := json.Marshal(map[string]string{"task_id": res.TaskID})
			ackResp, err := client.Post(apiURL+"/ack-task", "application/json", bytes.NewBuffer(ackBody))
			if err == nil {
				fmt.Printf("[✓] Задача %s успешно подтверждена\n", res.TaskID)
				ackResp.Body.Close()
			}
		}
	}
}
Use code with caution.
ЧАСТЬ 3. Код агента на PowerShell
Отличный вариант для Windows-инфраструктуры. Использует встроенный командлет Invoke-RestMethod.
powershell
$ApiUrl = "http://localhost:8000"
$AgentId = "win_agent_01"

Write-Host "[*] Агент $AgentId запущен на PowerShell..." -ForegroundColor Cyan

while ($true) {
    try {
        # Запрашиваем задачу. Увеличиваем TimeoutSec до 30 секунд.
        $Response = Invoke-RestMethod -Uri "$ApiUrl/get-task?agent_id=$AgentId" -Method Get -TimeoutSec 30
        
        if ($Response.status -eq "no_tasks") {
            # Просто пустой лонг-полл таймаут, идем дальше без задержки
            continue
        }
        
        if ($Response.status -eq "success") {
            $TaskId = $Response.task_id
            Write-Host "[~] Получена задача $TaskId. Данные: $($Response.data | ConvertTo-Json -Compress)" -ForegroundColor Yellow
            
            # --- Имитация выполнения работы агентом ---
            Start-Sleep -Seconds 1
            
            # Отправка подтверждения (ACK)
            $AckBody = @{ task_id = $TaskId } | ConvertTo-Json
            $AckResponse = Invoke-RestMethod -Uri "$ApiUrl/ack-task" -Method Post -Body $AckBody -ContentType "application/json"
            
            if ($AckResponse.status -eq "confirmed") {
                Write-Host "[✓] Задача $TaskId успешно выполнена и подтверждена!" -ForegroundColor Green
            }
        }
    }
    catch {
        Write-Host "[!] Ошибка запроса к API: $_. Повтор через 5 секунд..." -ForegroundColor Red
        Start-Sleep -Seconds 5
    }
}
